CSCI 1101 - Class 5 - Loops: while and for

These are the programs from the class. Open the folder in VS Code,
pick a file, read the comment at the top, compile it, run it,
and then do the "Try" list. Changing a program is the best way to learn it.

If a program does not stop: click inside the terminal, hold Ctrl, press C.

01_hello_copy_paste.c            Prints Hello five times WITHOUT a loop: the same line, copied five times.
02_hello_loop.c                  Prints Hello five times WITH a loop: one printf, and a line that says "do this 5 times".
03_hello_n_times.c               Asks how many times, then prints Hello that many times.
04_count_while.c                 Counts from 1 to 3 with a while loop, then prints Done.
05_count_zero_times.c            The same loop, but count starts at 10.
06_trace_while.c                 The loop we traced on paper: it prints 1 2 3 4, and after the loop x is 5, not 4.
07_infinite_loop.c               A loop with NO update.
08_while_semicolon_bug.c         A semicolon straight after while (.
09_countdown_while.c             Counts DOWN from 5 to 1 with a while loop, then prints Liftoff!.
10_for_count.c                   Counts from 1 to 5 with a for loop.
11_for_scope_error.c             This program does NOT compile, on purpose.
12_for_squares.c                 Prints the numbers 1 to 5 and their squares.
13_same_loop_two_ways.c          The same counting, written with while and then with for.
14_countdown_for.c               Counts down from 5 to 1 with a for loop.
15_countdown_wrong_update.c      A count-down with the wrong update: i++ instead of i--.
16_post_and_pre_increment.c      a++ against ++a, when the value is used in the same line.
17_predict_x_plus_plus.c         The prediction from class.
18_compound_assignment.c         The five short forms: +=  -=  *=  /=  %=.
19_count_by_twos.c               The update does not have to be i++.
20_sum_1_to_4.c                  Adds up 1 + 2 + 3 + 4 in a box called sum.
