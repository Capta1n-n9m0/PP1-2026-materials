CSCI 1101 - Class 9 - Linear arrays

These are the programs from the class. Open the folder in VS Code,
pick a file, read the comment at the top, compile it, run it,
and then do the "Try" list. Changing a program is the best way to learn it.

Files 19 to 21 are the solutions of the three tasks. Try the task first.

01_recap_add_ten.c             The recap question from the start of class: a function changes its parameter.
02_five_variables.c            Five quiz scores in five separate variables, WITHOUT an array.
03_five_array.c                The same five scores, WITH an array.
04_declare.c                   Makes an array of 5 ints, puts a value into three of its boxes one at a time, and prints them.
05_days_in_month.c             An array filled with a list in braces: the number of days in each month (not a leap year).
06_partial_list.c              A list in braces that is shorter than the array.
07_prices.c                    An array of double values: three prices.
08_index_and_value.c           Prints every position of an array next to the value in it: the index on the left, the value on the right.
09_fill_squares.c              Fills an array with a loop (box i gets i times i), then prints it with a second loop.
10_read_five.c                 Reads 5 whole numbers from the keyboard into an array, then prints them back.
11_sum_average.c               Reads 5 scores into an array, then adds them up with a loop and prints the sum and the average.
12_reverse.c                   Reads 5 numbers and prints them backwards.
13_define_n.c                  The sum and average program again, with the size written ONCE at the top: #define N 5.
14_above_average.c             Why we need the array: reads 5 scores, finds the average, and THEN counts how many scores are above it.
15_bug_le.c                    THIS PROGRAM HAS A BUG, on purpose.
16_bug_index_5.c               THIS PROGRAM HAS A BUG, on purpose.
17_bug_assign.c                THIS PROGRAM DOES NOT COMPILE, on purpose.
18_copy_loop.c                 Copies an array the right way: one box at a time, in a loop.
19_task_temps.c                Solution of task 1: reads the temperatures of the 7 days of a week into an array, prints them, and prints the average.
20_task_double_all.c           Solution of task 2: doubles every value IN the array with one loop, then prints the array with a second loop.
21_task_even_count.c           Solution of task 3: counts how many values in the array are even.
